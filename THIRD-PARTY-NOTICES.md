# Third-party notices

The NewsDesk installers bundle the open-source components listed below. Each component remains under its own
licence; the licence texts are available at the linked project pages. Component versions change between releases;
the list reflects the build environment at the time of NewsDesk 0.3.0.

## Qt and PySide6 (GNU LGPL v3)

NewsDesk uses the Qt framework through PySide6 (Qt for Python), copyright The Qt Company Ltd and other
contributors, under the GNU Lesser General Public License version 3 (https://www.gnu.org/licenses/lgpl-3.0.html).
Qt and PySide6 are included as separate, unmodified dynamic libraries in the program folder, so they can be replaced
with other builds of the same libraries. Their source code is available from https://download.qt.io/official_releases/QtForPython/
and https://code.qt.io/.

## Python

The installers include the CPython interpreter and standard library, under the Python Software Foundation License
Version 2 (https://docs.python.org/3/license.html).

## PyInstaller bootloader

The program is packaged with PyInstaller (https://pyinstaller.org). Its bootloader is distributed under the GPL
with a special exception that permits its use in programs under any licence.
